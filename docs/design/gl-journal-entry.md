# 总账模块 — 凭证录入详细设计

## 双模式交互设计

### 模式 A：专业会计模式（类 Excel）
- 网格录入，Tab/Enter 导航
- 快捷键：F2 编辑 / Ctrl+S 保存 / Ctrl+N 新建
- 自动借贷平衡检查
- 批量复制粘贴
- = 自动计算借贷差额

### 模式 B：AI 智能模式（自然语言）
1. 用户描述业务 → AI 解析 → 展示借贷建议
2. 三档置信度交互：
   - ≥90%：自动填充 + 一键确认
   - 70-89%：推荐科目 + 可选替代
   - <70%：转人工处理

## AI 能力矩阵
| 模块 | 准确率目标 | 覆盖角色 |
|------|-----------|---------|
| 科目智能推荐 | 85% | 非财务人员 |
| 自然语言转凭证 | 80% | 全部 |
| OCR 发票识别 | 95% | 全部 |
| 银行对账匹配 | 90% | 专业会计 |
| 费用合规检查 | 95% | 业务员工 |
| 账龄预测预警 | 85% | 财务经理 |

## 凭证审核流程
```
编制 → 提交 → 审核 → 过账
  │       │       │       │
  ▼       ▼       ▼       ▼
可修改  锁定   可驳回   不可修改
       等待    可修改   影响余额
```
